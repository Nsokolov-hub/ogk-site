# Админка ogk-chem.ru

React 19 · Vite · TanStack Query · React Router (ТЗ 13). Вход для сотрудников: пароль, код из приложения (TOTP, обязателен администраторам), сессия в httpOnly cookie, CSRF на каждое изменение. API — `/api/v1/admin/*` бэкенда сайта (`backend/app/admin`).

## Разработка

```bash
cd admin
npm install
npm run dev        # http://127.0.0.1:5174, /api проксируется на API сайта (API_ORIGIN, по умолчанию http://127.0.0.1:8001)
npm run build      # проверка типов и сборка в dist/
```

Первый сотрудник: `docker compose exec api python -m app.admin.cli create-user --email you@ogk-chem.ru --name "Имя" --role admin` — пароль печатается один раз.

## Что где

- `src/api.ts` — клиент API с CSRF; `src/auth.tsx` — сотрудник и права его роли.
- `src/shape.tsx` — редактор текста страницы по форме полей: строки, абзацы, списки, вложенные блоки, блоки статьи.
- `src/pages/EntityEditor.tsx` — черновик, предпросмотр на сайте, публикация сейчас или по расписанию, версии из журнала: страницы, разделы, бренды, субстанции, SEO-посадочные.
- `src/pages/ProductEditor.tsx` — карточка товара по типу: химия, хранение, тексты, фасовки, документы, разделы и связи, SEO, история.
- `src/pages/Imports.tsx` — мастер импорта (файл → колонки → предпросмотр → загрузка) и журнал партий с откатом.
- Остальное — разделы меню: очереди, справочники, SEO, заявки и подписчики, настройки, сотрудники, журнал.

## Роли

| Роль | Может |
|---|---|
| Администратор | всё, включая сотрудников, настройки и персональные данные заявок и подписчиков |
| Контент и SEO | страницы, тексты разделов, брендов и субстанций, SEO-посадочные, редиректы, шаблоны, robots.txt |
| Каталог-менеджер | товары, импорт, очереди, справочники, бренды, субстанции, фид |
| Просмотр | всё смотреть, ничего не менять, без персональных данных |

На сервере статику отдаёт Caddy на `ADMIN_DOMAIN` (`deploy/caddy.Dockerfile`, `deploy/caddy/admin.caddy`).
